# Memory Poster Editorial

Use the system `imagegen` skill and image-generation tool. This is an edit of the supplied photographs, not a brand-new unrelated illustration.

## Output contract

- Treat every uploaded photo as a separate edit target and return one independent raster poster per photo. Never combine multiple source photos into one canvas, contact sheet, diptych, or collage.
- Use a 3:4 portrait canvas for every output.
- Build a clear upper/lower two-layer composition: the upper half remains truthful photography; the lower half is a selective-memory flat reconstruction derived from the same source.
- Preserve the subject's identity, count, structure, pose, silhouette, spatial relationship, natural light, photographic texture, and original color atmosphere in the upper half. Extend background only when needed for the ratio; never stretch, warp, or redesign the subject.
- Use very little text. Do not invent fixed titles, numbers, locations, logos, labels for every sticker, or pseudo-information. Add only a small meaningful phrase when it genuinely arises from the image's subject, action, setting, mood, sound, memory, or cultural context.

## Design logic

The upper half should feel like art-magazine, independent-publication, or exhibition photography: restrained, high-end color correction only. It must still read as a real photograph at thumbnail size.

The lower half should compress the scene into 3–6 large visual masses using opaque gouache, paper cutouts, Risograph, or screen-print-like flat color. Preserve only the most memorable cues rather than tracing the whole scene. Keep the main reconstruction clearly larger and more important than six smaller memory fragments.

Select exactly six source-derived sticker motifs for the lower half. Each sticker may depict a recognizable feature, gesture, structural detail, plant, object, vehicle, food, pattern, material, light effect, or incidental detail. Give the six stickers a thick pale cut edge and arrange them in a loose, asymmetrical distribution: varied scale, slight rotation, overlap, edge crossing, or orbit around the main visual are welcome. Avoid six equal icons, a six-cell grid, a product catalog, or evenly spaced labels. Keep enough quiet background so the stickers feel like collected fragments from one memory.

Resolve hierarchy through visual weight, block proportion, scale contrast, positive/negative shape, overlap, and breathing room. The main lower visual must dominate; stickers support recognition and rhythm without stealing the focal point. Delete complicated environmental detail and let a large calm background color carry the composition.

## Material and palette

- Use one coherent tactile language for the main lower reconstruction and all stickers: matte opaque gouache, cut paper, Risograph, or screen-print flat fills.
- Retain subtle powdery edges, paper grain, handmade cut edges, and restrained registration drift. Keep the craft physical but refined.
- Use a soft, airy, slightly desaturated palette derived from the source. The main atmosphere should be pale pink-blue, mist blue, sky blue, or cool air-like blue.
- Balance with ivory, cream, pale beige, soft gray-green, and architectural neutrals.
- Permit only tiny dusty-rose or muted-blush accents for a flower, garment, small sign, awning, or local ornament.
- Do not use watercolor bleeding, complex brushwork, dense line art, realistic lower-half texture, glossy vector gradients, plastic 3D stickers, cartoon/anime styling, or e-commerce asset polish.

## Prompt compilation

Before calling image generation, inspect each source and privately determine: the hero subject, its defining silhouette or gesture, the six most memorable sticker motifs, the source-derived cool palette, the simplest lower-half mass structure, and one restrained text opportunity (or none).

Then compile a direct spatial prompt containing:

1. independent 3:4 portrait output and the upper/lower split;
2. photographic preservation invariants and any safe background extension;
3. the lower reconstruction's 3–6 broad masses and its selective-memory interpretation;
4. the six specific sticker motifs, their hierarchy, varied sizes, loose asymmetric placement, pale cut edges, and ample negative space;
5. the eye path, overlap, scale contrast, and quiet background shape;
6. the shared matte print/cut-paper material language and restrained palette;
7. any minimal meaningful text, placed in a quiet gap and kept subordinate;
8. hard exclusions: no source-photo montage, no multi-photo canvas, no distorted subject, no full-scene literal redraw, no six equal stickers, no six-grid/catalog layout, no generic decorations, no dense detail, no commercial postcard template, no cartoon/anime, no watermark.

Do not quote, restate, or display the user's design brief. Treat it as internal production direction and proceed directly to image editing. The assistant's user-facing response should contain only the resulting independent images and, if needed, one short status sentence.

## Inspect and correct

Review each generated poster at full size and thumbnail size. If one looks like a filtered photograph, strengthen the lower flat reconstruction and reduce decorative overlay. If it looks like a full illustration, restore real photographic detail in the upper half. If the lower section is busy, merge details into larger masses and restore quiet space. If the stickers compete with the main visual, reduce their size/contrast and increase hierarchy. If the result becomes a catalog or grid, make sticker placement more asymmetrical and varied. Regenerate with one targeted correction when needed.

Return all independent images, clearly one per source photo, with no promotional copy.
